# ZapretA

[English](README.md) | [Русский](README_RU.md)

**ZapretA — это программа для Windows в разработке.** В перспективе она должна сама проверять доступ к сайтам и подбирать подходящий способ обработки сетевого трафика. Проект пишется на Rust.

> **Статус:** ранняя разработка. Реализованы Rust workspace, проверка каталога, безопасная граница запуска движка и первая ручная диагностика DNS/HTTPS (`--diagnose`). Автоподбор, встроенный движок, значок в трее и готовый релиз пока отсутствуют.

## Зачем нужен проект

Иногда сеть мешает подключению к отдельным сайтам. Причина может быть разной: DNS возвращает неправильный адрес, соединение обрывается при установке защищённого соединения или скорость падает уже после начала загрузки. Простая проверка «сайт отвечает или нет» не всегда показывает, в чём проблема.

Идея ZapretA — проверить разные этапы соединения и сравнить их с контрольным сайтом, который должен открываться. Затем программа будет проверять поддерживаемые стратегии по одной. Одновременный запуск нескольких стратегий может привести к конфликту, поэтому перед следующей проверкой предыдущая должна быть остановлена.

Если проверка покажет, что стратегия помогает, программа оставит её включённой и покажет состояние в системном трее Windows. По задумке, трафик обрабатывается локально — программа не должна отправлять его через удалённый VPN или прокси.

Это цель проекта, а не уже готовая возможность. Результат будущих проверок будет зависеть от сети, настроек безопасности Windows и типа сетевой фильтрации.

## Сборка и запуск

Пример каталога можно проверить командой `cargo run -p zapreta -- --validate-catalog catalog/format-example.toml`. Это только пример формата: он не запускает обход. Команда `cargo run -p zapreta -- --diagnose` делает прямые DNS-запросы к системному резолверу и `dns.google`, а также ограниченные HTTPS-запросы к `www.youtube.com` и `example.com`. Она не меняет системные настройки, не запускает движок и не доказывает наличие DPI. Диагностику можно запускать только если вы согласны с этими сетевыми запросами. Для проверки сборки используйте `cargo test --workspace` и `cargo clippy --workspace --all-targets -- -D warnings`. Готового `.exe` пока нет. Не скачивайте исполняемые файлы со сторонних сайтов, которые называют себя сборками ZapretA.

Настройка Rust/MSVC и описание CI: [docs/DEV_SETUP.md](docs/DEV_SETUP.md). [Windows CI прошёл](https://github.com/alexkuz2014/ZapretA/actions/runs/41042507801) и загрузил временный `.exe` с файлом SHA-256 как артефакт workflow; это не официальный релиз и не подписанный бинарник.

## Безопасность

Предполагаемый способ работы может требовать драйвер Windows для обработки сетевых пакетов и прав администратора. Поэтому перед публикацией каждого бинарного компонента нужно указать его источник, лицензию, версию и контрольную сумму SHA-256. До проверки происхождения такие файлы не должны попадать в релиз.
