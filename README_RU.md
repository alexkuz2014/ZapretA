# ZapretA

[English](README.md) | [Русский](README_RU.md)

**ZapretA — это будущая программа для Windows, которая должна сама проверять доступ к сайтам и подбирать подходящий способ обработки сетевого трафика.** Проект пишется на Rust и сейчас находится на этапе исследования и проектирования.

> **Статус:** приложение ещё не реализовано. Исполняемого файла, установщика и готового автоматического подбора пока нет.

## Зачем нужен проект

Иногда сеть мешает подключению к отдельным сайтам. Причина может быть разной: DNS возвращает неправильный адрес, соединение обрывается при установке защищённого соединения или скорость падает уже после начала загрузки. Простая проверка «сайт отвечает или нет» не всегда показывает, в чём проблема.

Идея ZapretA — проверить разные этапы соединения и сравнить их с контрольным сайтом, который должен открываться. Затем программа будет проверять поддерживаемые стратегии по одной. Одновременный запуск нескольких стратегий может привести к конфликту, поэтому перед следующей проверкой предыдущая должна быть остановлена.

Если проверка покажет, что стратегия помогает, программа оставит её включённой и покажет состояние в системном трее Windows. По задумке, трафик обрабатывается локально — программа не должна отправлять его через удалённый VPN или прокси.

Это цель проекта, а не уже готовая возможность. Результат будущих проверок будет зависеть от сети, настроек безопасности Windows и типа сетевой фильтрации.

## Сборка и запуск

Пока собрать или запустить ZapretA нельзя: исходного кода приложения и `Cargo.toml` ещё нет. Не скачивайте исполняемые файлы со сторонних сайтов, которые называют себя сборками ZapretA.

## Безопасность

Предполагаемый способ работы может требовать драйвер Windows для обработки сетевых пакетов и прав администратора. Поэтому перед публикацией каждого бинарного компонента нужно указать его источник, лицензию, версию и контрольную сумму SHA-256. До проверки происхождения такие файлы не должны попадать в релиз.
